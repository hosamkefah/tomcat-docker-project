# Custom Tomcat Docker Project 🚀

This project automates the deployment of a Tomcat 9 Web Server using Docker.
It includes a custom configuration and a sample "Hello World" WAR file.

## 🐳 Docker Hub Image
You can pull the pre-built image from Docker Hub here:
**[hussam101/my-tomcat-app](https://hub.docker.com/r/hussam101/my-tomcat-app)**

## 🛠 How to Run
To start the container on port 8080, run:

```bash
docker run -d -p 8080:8080 hussam101/my-tomcat-app
